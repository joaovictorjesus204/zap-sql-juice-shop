# Modelo de relato de defeito

| Campo | Preencher com |
|---|---|
| **ID** | DEF-000 |
| **Título** | O que acontece, onde e em que condição (ex.: "Cadastro aceita senha com 41 caracteres") |
| **Caso de teste** | CT-00 |
| **Severidade** | Crítica · Alta · Média · Baixa (impacto no sistema) |
| **Prioridade** | P1 · P2 · P3 (urgência de correção) |
| **Ambiente** | URL, versão do app, navegador e versão, sistema operacional |
| **Pré-condição** | Estado necessário antes dos passos |
| **Passos para reproduzir** | Numerados, um por linha, com os dados usados |
| **Resultado obtido** | O que aconteceu, com a mensagem exata |
| **Resultado esperado** | O que deveria acontecer, com a referência (regra, caso de teste ou requisito) |
| **Evidências** | Print ou vídeo, e trecho do log ou da aba Network |
| **Frequência** | Sempre · Intermitente (x de y tentativas) |
